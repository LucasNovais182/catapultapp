# LoL Cannon Timer Overlay

![status](https://img.shields.io/badge/status-WIP-orange)

A minimal, semi-transparent desktop overlay for League of Legends. It provides a simple, clean UI that tracks the exact time until the next cannon minion wave spawns for the Mid and Side lanes (Top/Bot).

Designed to be small, unobtrusive, and "click-through" so it doesn't interrupt your gameplay.

## Features

- Minimal Interface: Clean, small, and inspired by modern gaming overlays.

- Semi-Transparent: Dark, semi-transparent background that blends in.

- Real-time Timers:

- Separate timer for the Mid Lane cannon.

- Separate timer for the Side Lane (Top/Bot) cannons.

- Draggable: Move it anywhere on your screen.

## How to Install & Run

This app is built with Electron. You must have Node.js installed on your computer.

1. Clone the Repository:
Open your terminal, navigate to where you want to store the project, and run:

git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git


2. Then, navigate into the new folder:

cd YOUR_REPOSITORY_NAME


3. Install Dependencies:
Open a terminal (CMD, PowerShell, etc.) in that folder and run:

npm install


4. Run the App:
Once the installation is complete, run:

npm start
